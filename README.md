# nix updater
Update nix by typing "nixupdate" in your terminal, wrote in bash simple but useful.

To be able to use the script by typing "nixupdate" do these steps:
1) "mkdir -p ~/.local/bin"
2) Make sure you are in the dir that the nixupdate.sh is in and run this "cp nixupdate.sh ~/.local/bin/nixupdate"
3) Give perms "chmod +x ~/.local/bin/nixupdate"
4) Export to path "export PATH="$HOME/.local/bin:$PATH""

After that open a net terminal and type "nixupdate"

Includes simple error handling.
